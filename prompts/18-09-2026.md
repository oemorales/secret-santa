# Prompt 1
Generate the starting constitution for a web aplication project named secret-santa.
Create a subfolder "specs" with the following files: tech-stack, roadmap and plan.
This is the general idea of the aplication:
 -web app friendly for any kind of user, used to manage "secret santa"-like gift exchange activities.
 -divide the complexity od the app in frontend, backend and database
 -audience is general public as gift exchange participant, and a little more advanced users for administrators.
 -the app must store data for each user, username, display name per "gift-exchange" joined, password, profile pic, area and role
 -the app can handle multiple "gift-exchange", one user can create them if has a certin role "organizer"
 -in each "gift-exchange" there must be a rule for which users can join established by area
 -once the "gift-exchange" has enough users (2) a draw can be made to set sender and receiver relationships for each participant.
 -certain rules can be established for each "gift-exchange" draw, like:
    -sorting the relationships in a way that there is just one round trip around all participants or if it is allowed to have multiple separated groups
    -setting rules so certain users can't gift/receive from other users by name or by area or by subgroups which can be configured inside the "gift-exchange"
 -once the draw if made, each user can see who they should gift a present.
 -once the draw is made, each user can add items to their wishlist so their secret sana who must gift to them can see them.
 -a "gift-exchange" must have an event-date and after this date (or when the administrator set this "gift-exchange" as done) everyone can see all the relationships sender-receiver.
Use the "ask before writting mode" and "ask questions to clarify ideas" and correct gramatical errors and typos.
